# Normativa de accesibilidad

Este resumen es informativo. Para decisiones de cumplimiento se debe consultar siempre el texto oficial vigente y el ámbito exacto del producto o servicio.

## España y Unión Europea

- El [Real Decreto 1112/2018](https://www.boe.es/eli/es/rd/2018/09/07/1112) regula la accesibilidad de sitios web y aplicaciones móviles del sector público español.
- La [Directiva (UE) 2019/882](https://eur-lex.europa.eu/eli/dir/2019/882/oj/spa), Acta Europea de Accesibilidad, establece requisitos para determinados productos y servicios. Sus medidas son aplicables desde el 28 de junio de 2025 en los supuestos previstos.
- España incorporó esa directiva, entre otras disposiciones, mediante la [Ley 11/2023](https://www.boe.es/buscar/act.php?id=BOE-A-2023-11022).
- La norma [UNE-EN 301 549:2022](https://www.une.org/encuentra-tu-norma/busca-tu-norma/norma?c=N0067038) especifica requisitos de accesibilidad para productos y servicios TIC y enlaza sus requisitos web con WCAG.

## Estándar técnico

WCAG es un estándar internacional del W3C, no una ley por sí misma. La norma o contrato aplicable determina qué versión, nivel y excepciones se exigen. Como objetivo de desarrollo, resulta razonable trabajar con [WCAG 2.2](https://www.w3.org/TR/WCAG22/) y documentar las condiciones concretas de conformidad.

La accesibilidad debe mantenerse: cambios de contenido, componentes o proveedores pueden introducir nuevas barreras después de una auditoría.
